SmartFinTrack logo files
========================
Put your own logo images in this folder. The dashboard picks them up
automatically by name - no code changes needed. Use .svg, .png, .webp or .jpg.
Download logos from each brand's official press / brand-assets page and
follow that brand's usage terms.

Naming: lowercase, spaces become hyphens. The full name is tried first,
then just the first word.

  Subscription "Netflix"            -> netflix.png
  Subscription "Google One"         -> google-one.png  (or google.png)
  Subscription "Amazon Prime"       -> amazon-prime.png (or amazon.png)
  Subscription "iCloud+"            -> icloud.png
  Subscription "Spotify"            -> spotify.svg
  Credit card  "HDFC Regalia"       -> hdfc-regalia.png (or hdfc.png)
  Credit card  "ICICI Amazon Pay"   -> icici-amazon-pay.png (or icici.png)
  Account      "SBI Savings"        -> sbi-savings.png (or sbi.png)
  Card network                      -> net-visa.png, net-mastercard.png,
                                       net-rupay.png, net-coral.png,
                                       net-amex.png, net-diners.png

Square images, at least 96x96 px, look best. A logo you upload in the app
(click the icon) overrides these files.
